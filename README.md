# AI_Final-Assessment_B230290C
An intelligent multi-criteria decision support system developed in Python for evaluating, ranking, and selecting academic reference eBooks across heterogeneous dataset catalogues. The framework combines Predicate Logic (crisp Boolean filtering) with Fuzzy Reasoning (multi-attribute preference scoring) for academic procurement scenarios.  📌 OverviewAcademic e-book collections often contain disparate schema structures, missing attributes (e.g., absent pricing information), and vague search criteria. This system resolves these limitations through a two-stage evaluation pipeline:  Predicate Logic Filtering: Filters out non-relevant titles based on domain-specific keyword taxonomies.  Fuzzy Suitability Scoring: Evaluates candidate titles along three continuous dimensions—Topic Relevance, Publication Recency, and Price Affordability—to generate a normalized suitability score $S \in [0.0, 1.0]$.  🎯 Evaluation ScenariosThe engine evaluates three distinct datasets across two academic procurement contexts:  Scenario 1: AI, Programming, & MathematicsDirect AI: Artificial intelligence, machine learning, computer vision, robotics, expert systems, knowledge representation.  Programming Support: Python, Java, C++, algorithms, data structures, software engineering, coding.  Mathematical Support: Statistics, probability, linear algebra, discrete math, calculus, optimization, decision analysis.  Scenario 2: Cybersecurity & Secure ComputingCybersecurity: Network security, cryptography, digital forensics, privacy, information assurance, secure systems.  🧮 Fuzzy Logic Architecture1. Topic Relevance Membership ($\mu_{Relevance}$)Measures keyword match density relative to scenario domain taxonomies:
  $$\mu_{Relevance} = \min\left(1.0, 0.5 + 0.15 \times N\right)$$(where $N$ is the total number of matched domain terms)  2. Publication Recency Membership ($\mu_{Recency}$)Evaluates title freshness using publication year $Y$ (benchmark year = 2026):  $Y \ge 2024$: $\mu_{Recency} = 1.0$ (Highly Recent)  $2020 \le Y < 2024$: $\mu_{Recency} = 0.7 + 0.3 \times \frac{Y - 2020}{4.0}$  $2015 \le Y < 2020$: $\mu_{Recency} = 0.3 + 0.4 \times \frac{Y - 2015}{5.0}$  $Y < 2015$: $\mu_{Recency} = 0.1$ (Outdated)  Missing Year: Default neutral fallback = $0.5$  3. Price Affordability Membership ($\mu_{Affordability}$)Evaluates financial accessibility based on list or net unit price $P$:  $P \le \$50.0$: $\mu_{Affordability} = 1.0$ (Highly Affordable)  $P \ge \$350.0$: $\mu_{Affordability} = 0.1$ (Expensive)  $\$50.0 < P < \$350.0$: $\mu_{Affordability} = 1.0 - 0.9 \times \left(\frac{P - 50.0}{350.0 - 50.0}\right)$  Missing Price (e.g., Dataset B): Default neutral fallback = $0.5$  4. Composite Suitability Score ($S$)Individual membership values are aggregated using a weighted linear combination:
  $$S = (w_{rel} \times \mu_{Relevance}) + (w_{rec} \times \mu_{Recency}) + (w_{aff} \times \mu_{Affordability})$$
Default Weights: $w_{rel} = 0.5$, $w_{rec} = 0.3$, $w_{aff} = 0.2$.  📁 Required DatasetsEnsure the following Excel files are placed in the working directory prior to running the program:  Dataset File NameCollection TypeKey Attributes ProcessedBTIS3043_Dataset_A_Existing_eBook_Collection.xlsxLocal Inventory (9 records)Title, Copyright Year, Unit Net Price  BTIS3043_Dataset_B_Academic_eBook_Catalogue.xlsxPublisher Catalogue (1,743 records)Title, Author, Disciplines (Price absent)  BTIS3043_Dataset_C_eBook_Acquisition_Catalogue.xlsxAcquisition Catalogue (807 records)Title, Author, Category, Discipline, April List Price  🛠️ Setup & RequirementsPrerequisitesPython 3.8 or higherpandasnumpyopenpyxlInstallationBash# Clone or download the repository
