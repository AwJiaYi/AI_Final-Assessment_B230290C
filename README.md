# AI_Final-Assessment_B230290C
#Setup & Requirements
## Prerequisites
Python 3.8 or higher
pandas
numpy
openpyxl
## Installation
### Clone or download the repository
`git clone https://github.com/your-username/intelligent-ebook-evaluator.git`
`cd intelligent-ebook-evaluator`
### Install required Python packages
`pip install pandas numpy openpyxl`
## Running the Evaluator
### Execute the script directly via terminal:
`python main.py`
The script will automatically preprocess all three datasets, run Predicate Logic filtering, compute Fuzzy Suitability scores, and output both Predicate-Only (unranked) and Fuzzy-Enhanced (ranked) top results to the terminal.
